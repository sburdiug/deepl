# Лабораторна робота №1

## Мета

Реалізувати пряме та зворотне поширення похибки для невеликої повнозв'язної нейронної мережі на NumPy і незалежно перевірити ручні градієнти.

## Дані та модель

Використано набір даних Iris. Ознаки стандартизуються за статистиками навчальної вибірки. Дані поділено стратифіковано: по 35 об'єктів кожного класу в train, решта - у test. У перевірках використовується навчальний батч розміру 105.

Модель:

```text
Linear(4, 8) -> ReLU -> Linear(8, 3)
```

Параметри ініціалізуються відтворювано (`seed=0`): для `W1` застосовано He-ініціалізацію, для `W2` - Xavier-ініціалізацію, зміщення дорівнюють нулю.

## Реалізація

- `model.py` містить `forward()` з чисельно стабільними `log-softmax` і середньою cross-entropy, а також ручний `backward()`.
- У зворотному проході початковий сигнал має вигляд `(softmax(logits) - one_hot(y)) / N`.
- Градієнти параметрів другого шару обчислюються через `A1.T @ d_logits`, після чого сигнал проходить через `W2.T` та маску похідної ReLU.
- `checks.py` містить незалежну звірку з PyTorch та чисельну перевірку центральною різницею.
- `main.py` виконує один відтворюваний запуск усіх перевірок.

## Перевірка

Ручні градієнти порівнюються з градієнтами PyTorch для всіх `W1`, `b1`, `W2`, `b2`. Допуск для максимальної абсолютної різниці - `1e-12`.

Додатково центральною різницею з `epsilon=1e-6` перевіряються елементи `W1[0, 0]`, `b1[0]`, `W2[0, 0]` і `b2[0]`. Допуск - `1e-7`.

Коректна реалізація проходить обидві перевірки. У додатковому досліді навмисно пропускається ділення на розмір батчу у `backward()`: значення loss не змінюється, але ненульові градієнти збільшуються у `N` разів. Обидві незалежні перевірки виявляють цю помилку.

## Запуск

```powershell
python lab1/main.py
```

## Висновок

Було реалізовано та перевірено ручний прямий і зворотний проходи для класифікатора `4 -> 8 -> 3`. Звірка з PyTorch і чисельними похідними підтверджує правильність реалізації градієнтів та здатність перевірок виявляти помилку усереднення за батчем.
